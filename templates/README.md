# Templates

Introduced in **Chapter 11** of *The Agentic Lab*.

**Status:** skeleton. The templates land with the chapter.

Chapter 11 ships no build. What it ships is paperwork: the documents you need
around an agent rather than inside it. This folder is where they live, and
`lab.nexagenlabs.com/ch11` points here.

The folder exists ahead of its contents because that URL is printed in the
book. A printed URL that resolves to nothing is not a gap somebody fixes
later; it is a dead link in an object that cannot be patched.
