Reporting one

Please report anything that looks wrong, including in the code. Two ways, and neither is preferred:

  • Open an issue at github.com/nexagenlabs/agentic-lab/issues.
  • Or email biotech.suryaprakash@gmail.com, if you would rather not use GitHub.

It helps to include the printing, which is on the copyright page, and the page number. For code, the build folder and the failing command are enough.

Code corrections

Where a correction affects code rather than prose, the repository is fixed as well, and the commit is the record. The listings in listings/ are what the book prints, and a test asserts the repository still matches them, so a divergence between page and code shows up as a failing build rather than as a reader's afternoon.
