# MODELS.md

**Last updated: 2026-08-28**

Chapter 2 of *The Agentic Lab* argues that you should choose a model by
capability tier rather than by name, because names change faster than books
do. This file holds the current names. The tiers do not change; this list
does.

Every build in this repository reads its model name from a single config
file, so updating this page and that file is the whole migration.

## Current tiers

| Tier | Representative models | Notes |
|---|---|---|

| Balanced workhorse | | The default for most steps |
