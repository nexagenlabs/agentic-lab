Most likely one character of a printed URL went astray. That is easy to do and it should not cost you anything.

Go to the hub, which lists every build and the address printed for it.

Two addresses people try that were never printed: /ch01 and /ch02. Chapters 1 and 2 ship no code, so there is nothing behind them. Sending you to a build anyway would be worse than this page, because you would have no way to tell it was the wrong one.

The addresses that do exist:

  • /setup, Chapter 0
  • /ch03 through /ch12, except that there is no chapter page without code behind it
  • /references, Appendix D
  • /errata.html, corrections to the book

If you typed it correctly and landed here, that is worth knowing about: please report it. A printed URL that does not resolve is a defect in the book rather than a mistake you made.
